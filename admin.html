⚙️ Pengaturan Deploy

🔑 GitHub Token

Token GitHub diperlukan untuk deploy otomatis ke live site. Token ini disimpan di browser Anda dan tidak dikirim ke server lain.

Buat token di github.com/settings/tokens dengan scope "repo"
📋 Cara Deploy:
  1. Buat atau edit kampanye di halaman Dashboard
  2. Klik tombol "🚀 Deploy ke Live Site"
  3. Tunggu proses upload selesai (beberapa detik)
  4. Kampanye akan muncul di twibbon.daarulazmi.ponpes.id
